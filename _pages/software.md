# SignLanguageDetectorCV
[![GitHub](https://img.shields.io/badge/GitHub-Repository-black.svg?logo=github)](https://github.com/jaypunekar/SignLanguageDetector)

**Tech Stack**: Flask, YOLOv5, Docker, AWS, Python

This project is a real-time web application for detecting and interpreting sign language gestures. It uses YOLOv5 for gesture detection, Flask to provide a user-friendly web interface, and Docker for containerization. Deployed on AWS, the app is scalable, accessible, and optimized for real-world conditions like varying lighting and gesture speeds.

## Features
- **Real-Time Gesture Detection**: Utilizes YOLOv5 for accurate and efficient detection of sign language gestures.
- **Web-Based Interface**: Built with Flask for seamless user interaction.
- **Scalable Deployment**: Containerized with Docker and deployed on AWS for high availability and performance.
- **Robust Optimization**: Handles diverse input conditions such as lighting variations and dynamic gesture speeds.

# AttendanceSystemCV
[![GitHub](https://img.shields.io/badge/GitHub-Repository-black.svg?logo=github)](https://github.com/jaypunekar/Face-Recognition-Attendance-System)

**Tech Stack**: Flask, OpenCV, SQLite, Python, HTML/CSS

This system automates attendance tracking using real-time facial recognition and provides a web interface for seamless user interaction. It is built with Flask to manage the backend, OpenCV for accurate face detection and recognition, and SQLite for securely storing attendance records. The system is designed to be lightweight and optimized for local deployment, ensuring efficient and reliable operation.

## Features
- **Real-Time Facial Recognition**: Detects and identifies faces accurately using OpenCV under varying conditions.
- **Integrated Web Interface**: Flask powers a simple and user-friendly interface for managing and viewing attendance logs.
- **Lightweight Design**: Optimized for local deployment with minimal hardware requirements.
- **Secure Data Storage**: Uses SQLite to safely store attendance records while maintaining privacy.

# AutoVoucherTally
[![GitHub](https://img.shields.io/badge/GitHub-Repository-black.svg?logo=github)](https://github.com/jaypunekar/AutoVoucherTally)

**Tech Stack**: Python, Customtkinter, MongoDB Atlas

The <b>Voucher Automation Software Suite</b> is a streamlined solution for automating voucher management processes. Developed using Python, MongoDB Atlas (NoSQL database), XML, CustomTkinter, and Tkinter, this suite includes three integrated applications:

1. <b>TallyClient:</b> Allows users to create and store vouchers in MongoDB Atlas.
2. <b>TallyMain:</b> Approves vouchers based on predefined rules and integrates them with Tally ERP 9.
3. <b>TallyAccounts:</b> Handles payment processing of approved vouchers, requiring payee signatures for authorization and marking vouchers as "paid" before integration back into Tally ERP 9.

This suite enhances efficiency, accuracy, and real-time financial management for businesses.
